# Pair Analyst (Analytical Syndicate)

**Files:** `python/agents/candle_agent.py`, `python/agents/order_book_agent.py`, `python/agents/oi_funding_agent.py`, `python/agents/news_agent.py`, `python/agents/indicator_agent.py`

## Overview
In the AI-Futures-Trader architecture, the "Pair Analyst" is not a single entity, but rather a collective term for a syndicate of specialized, parallel-processing AI agents. Each agent in this group is laser-focused on one specific dimension of the market data for a chosen DEX asset. This modular design prevents a single LLM prompt from becoming overwhelmed with too much diverse data.

## The Syndicate Members
1. **Candle Agent:** Analyzes OHLCV data to determine price action, chart patterns, and local support/resistance levels.
2. **Order Book Agent:** Evaluates DEX liquidity, bid/ask spread, and order walls to gauge immediate buy/sell pressure and potential slippage.
3. **OI Funding Agent:** Examines derivatives data (Open Interest and Funding Rates) to detect leverage buildup and anticipate potential short/long squeezes.
4. **News Agent:** Scans recent headlines and social sentiment to provide fundamental context and identify potential volatility catalysts.
5. **Indicator Agent:** Calculates and interprets standard technical indicators (RSI, MACD, Bollinger Bands) to assess market momentum.

## Input / Output Flow
* **Input:** Each analyst receives a tailored slice of the `MarketSnapshot` generated by the `MarketDataService`. For example, the Candle Agent only sees price data, while the Order Book Agent only sees liquidity depth.
* **Output:** Every agent outputs a strict JSON payload containing a directional bias (`BULLISH`, `BEARISH`, `NEUTRAL`) and a brief analytical summary.

## System Integration
These agents operate strictly in parallel. The orchestrator (`main.py`) triggers all of them simultaneously using asynchronous calls (e.g., `asyncio.gather`). Once all reports are generated, they are bundled together and forwarded to the `CEO_Agent` for the final decision.
